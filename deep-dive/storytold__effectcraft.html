和 After Effects 的不同

After Effects 是图形界面驱动的，项目文件是二进制的，难以版本控制和脚本化。effectcraft 走的是另一条路：所有动效都用 JSON 描述，可以用 Git 管理，也可以用代码生成。

内置 308 个效果，支持 Lottie 导入导出。引擎可以通过 CLI、JSON 控制通道或 MCP 协议驱动，适合把动效合成纳入自动化流水线。

  • 纯 Rust 实现，性能可控
  • JSON 项目文件，可 diff、可版本控制
  • 308 个内置效果，Lottie 兼容
  • CLI / JSON / MCP 三种控制方式

适合场景

如果你需要批量生成标题动画、视觉特效，或者希望动效项目能像代码一样通过 Git 协作，effectcraft 是一个有趣的替代方案。但如果你习惯于 AE 的图形界面和实时预览，可能需要一段时间适应。

目前项目还在活跃开发中，部分高级功能可能尚未完善。

  • 适合需要脚本化、自动化动效的团队
  • 适合希望动效项目可版本控制的开发者
  • 不适合完全依赖 AE 图形界面的用户

我的结论

effectcraft 是「动效合成也可以是代码」的一个坚实尝试。如果你的工作流里需要大量重复性动效，或者希望动效文件能进 Git 管理，它值得一试。纯 Rust 实现也意味着性能和可移植性都有保障。
