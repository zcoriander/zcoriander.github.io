它到底在做什么

仓库引用费曼那句名言：「我造不出的东西，我就不理解。」它收集了一大批「从头重建某项技术」的分步指南，涵盖 3D 渲染器、AI 模型、增强现实、BitTorrent 客户端、区块链/加密货币、机器人、命令行工具、数据库、Docker、模拟器/虚拟机、前端框架、游戏、Git、内存分配器、网络栈、神经网络、操作系统、物理引擎、处理器、编程语言、正则引擎、搜索引擎、Shell、模板引擎、文本编辑器、视觉识别系统、体素引擎、Web 浏览器、Web 服务器等。

README 只列了目录和每个条目的简短描述，真正的教程内容都在外部链接（codecrafters.io）里。仓库本身极简：.gitattributes、ISSUE_TEMPLATE.md、README.md、一张横幅图。

每个技术下的教程通常是「先造最小可用版本，再逐步加功能」，适合边做边学，适合那种「自己实现一遍才踏实」的学习风格。

  • 30 多个技术方向，每个都有分步教程
  • 仓库极简，实质内容在外部链出的教程里
  • 适合「从零实现」学习派，不适合想直接复制粘贴可用代码的人

适合谁与门槛

适合喜欢通过实现来理解底层原理、有编程基础、愿意花时间跑通教程的自学者。

门槛取决于你选的技术（写 Git 比写 Web 浏览器低得多）；没有统一安装方式，每个教程自行说明。

实际使用建议

选一个你感兴趣且规模可控的技术先跑通（比如 Shell、正则引擎、一个最小 HTTP 服务器），不要试图一次把几十个方向都做完。教程都在外部链接里，链接偶尔会失效，卡住时可以去 codecrafters.io 原站看最新版。把自己实现的版本和标准实现对比，差距在哪里才是学习点；完成一个比半完成十个更有价值。

我的结论

本质上是一个精选的「自己动手造轮子」教程索引，而非一个可直接运行的代码仓库。适合通过「从零实现」来学习底层原理的自学者；仓库本身只有 README 和几个配置文件，所有实质内容都在链出的具体教程里。选哪个技术、跑多远，完全由你决定。
