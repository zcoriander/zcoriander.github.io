它的核心主张

craft-anything 不提供现成的软件，而是提供一套「从零理解再重建」的方法论和工具链。它的 README 明确写着：想搞懂某个软件怎么工作，最好的办法不是看文档，而是亲手把它用 Rust 重写一遍。

这和 codecrafters-io/build-your-own-x 的精神一致，但 craft-anything 更进一步——它不是索引教程，而是提供可直接跑通的 Rust 代码框架，让你在重建过程中拿到可运行的原型。

  • Rust 语言实现，性能和安全性并重
  • 强调「理解原理」而非「调用 API」
  • storytold 工具家族的一员，与 effectcraft/designcraft 等同源

适合谁

如果你只是想用某个软件，这个项目不适合你。它适合那些想深入理解图形渲染、音频处理、文档排版等底层机制的开发者，尤其是愿意用 Rust 重新实现一遍的人。

目前 210 个未关闭 issue 说明项目还在快速迭代，API 和功能可能会有较大变动。

  • 适合底层原理爱好者和 Rust 学习者
  • 不适合寻找现成工具的普通用户
  • 早期项目，接口可能变动

我的结论

craft-anything 不是给普通用户的工具，而是给「想亲手重建一遍」的开发者的实验场。如果你对 Rust 和软件底层原理感兴趣，值得关注；如果只想找个能用的软件，先绕道。
