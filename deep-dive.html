openclaw/openclaw

★ 394.1k TypeScript

把 AI 助手部署在你自己的机器上，然后让它住进你已经在用的聊天软件里。Discord、iMessage、Slack、WhatsApp、Telegram……20 多个平台，一个 Gateway 统一调度。

如果你想要一个「常驻在聊天软件里的私人助手」，目前生态里最完整的开源方案之一。架构上「策略由代码强制」那句话值得所有做 Agent 的人抄在墙上。适合有一定技术基础、愿意自己管一台机器的人；完全零基础的话，20 多个渠道的配置量会有点劝退。

obra/superpowers

★ 313.8k Shell

一套给编码 Agent 用的完整开发方法论——不是几个提示词，而是一套带自动触发机制的工作流。

如果你团队在用 AI 编码工具但产出质量忽高忽低，缺的不是模型而是流程约束。这个项目提供的正是流程。而且它明确反对「 vibe coding 」，跟我的看法一致：AI 降低了写代码的门槛，但没降低想清楚要什么的门槛。

阅读完整拆解 →

mattpocock/skills

★ 317.1k Shell

作者每天在用的 Agent 技能包，定位很明确：给「做真实工程」用，不是给 vibe coding 用。

和 Superpowers 是一对镜像：superpowers 是重流程、可自动触发；这个是轻流程、完全可控。两者都指向同一件事——AI 编码的瓶颈已经从「模型能不能写」转移到「流程约束得好不好」。想快速起步用前者，想深度定制用后者。

阅读完整拆解 →

shareAI-lab/learn-claude-code

★ 80k Python

从零手写一个 Claude Code 风格的 Agent Harness，重点不是用 Claude Code，而是理解它为什么这么设计。

这是我在这批项目里最推荐给「想理解而不是想直接用」的人的项目。README 的写作质量在开源项目里属于头部——论述清晰、有历史纵深、有明确的观点。读完你会发现，很多「AI 编程工具」的差异，本质是 harness 设计哲学的差异。

阅读完整拆解 →

ssloy/tinyrenderer

★ 24.5k C++

500 行裸 C++ 实现软件渲染器，用来教人搞明白 OpenGL / Vulkan / Metal / DirectX 底下到底发生了什么。

24k star 里我最推荐的一个。它代表了一类被低估的项目：代码量小得离谱，但它教的东西能迁移到你写的每一行图形/系统代码里。适合当作「学底层」的自修教材。

阅读完整拆解 →

codecrafters-io/build-your-own-x

★ 560.6k Markdown

从零复刻你喜欢的技术：数据库、操作系统、编译器、容器、Docker、Git……全是教程。

如果只能推荐一个「学习索引」，就是它。star 数 557k 说明它被反复验证过——但更重要的是它把「我想搞懂 X」变成了一条明确的行动路径。

donnemartin/system-design-primer

★ 377.2k Python

大规模系统设计的学习指南，还附带了 Anki 记忆卡，直接对着面试准备。

它的 Anki 卡片设计是我最喜欢的一点——把「读过」变成「记得住」。这比单纯又一个 Markdown 教程务实得多。新人如果正准备系统设计面试，这是最高性价比的起点。

freeCodeCamp/freeCodeCamp

★ 458.7k TypeScript

全球最大的免费编程学习平台，458k star，课程本身也是开源的。

如果你完全零基础，它是最稳的起点。缺点是它教的是 web 开发，如果你的目标是后端、系统或 AI，直接看它的证书项目有点绕——但那个项目本身质量不错，可以当跳板。

seedds/nxnative

★ 13.1k Python

把 Switch 游戏转成能在 iPhone/iPad/Mac 上原生运行的 IPA。不是模拟器，而是把 NSP 文件夹重写成未签名 IPA，游戏代码直接跑在 Apple 芯片上，图形层用 Metal 重建。仓库里不含任何游戏内容，只提供转换和运行框架。

如果你有合法的 Switch 游戏、一台 A17 Pro 以上的设备、又愿意折腾，这是目前最值得关注的「Switch 游戏在 Apple 设备上原生跑」的开源项目之一。但别把它当成成品游戏机——735 个 open issue 提醒你，这更像是一个技术预览，适合当学习对象或偶尔尝鲜，不适合当日常娱乐工具。
