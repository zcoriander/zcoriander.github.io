openclaw/openclaw

★ 393.6k TypeScript

把 AI 助手部署在你自己的机器上，让它「住进」你已在用的聊天软件：Discord、iMessage、Slack、Teams、Telegram、WhatsApp 等 20 多个渠道，一个 Gateway 统一调度。

如果你想要一个「常驻在聊天软件里的私人助手」，目前生态里最完整的开源方案之一。架构上「策略由代码强制」那句话值得所有做 Agent 的人抄在墙上。适合有一定技术基础、愿意自己管一台机器的人；完全零基础的话，20 多个渠道的配置量会有点劝退。

obra/superpowers

★ 310.6k Shell

一套给编码 agent 用的软件开发方法论：可组合的技能（skills）+ 初始指令，让 agent 在动手写代码前，先把需求、设计、计划过一遍。

它不是一个新编程语言，也不是一个 IDE，而是一套「让 agent 慢下来再动手」的方法论。对已经在用 Claude Code / Codex / Cursor 等 agent 的团队，值得把它当成标准作业程序（SOP）引入；对只偶尔写脚本的个人，则可能过于沉重。

mattpocock/skills

★ 309.2k Shell

作者日常用于真实工程的 agent 技能集合：小、易改、可组合，适用于任意模型，反对被 GSD / BMAD / Spec-Kit 这种重流程框架夺走控制权。

它的价值不在于「多少技能」，而在于「小而可组合」的哲学——每个技能都可以被你改、被你丢、被你只装一个。适合厌倦了重型 agent 框架、想自己掌控开发流程的工程师；不适合想要「一键全自动」的用户。

shareAI-lab/learn-claude-code

★ 79.7k Python

一本把「构建真正的 agent 产品」拆成可练习步骤的仓库：先讲「主体性（agency）来自模型训练，而非外部编排」，再教你搭建那个「车」（harness）—— agent 循环、工具调用、待办、子 agent、技能加载、上下文压缩。

如果你对「agent」一词被滥用感到困惑，这篇值得读。它把 agent 产品拆成「模型（驱动）」+「车架（harness）」，并用 s01–s06 逐步实现。适合想从头理解 agent 工作原理、并亲手写一个最小 agent 框架的开发者；不适合只想拖拽搭建流程的用户。

ssloy/tinyrenderer

★ 24.5k C++

用裸 C++、约 500 行代码写一个软件渲染器：从 Bresenham 线段、三角形光栅化、Z-buffer 隐面消除，到纹理贴图、切线空间法线贴图、阴影映射、间接光照，配套 14 篇配套课程笔记。

它想教你的不是「怎么调用 OpenGL/Vulkan/Metal/DirectX」，而是「这些图形库内部到底是怎么工作的」。适合想从底层理解 3D 图形、愿意动手写渲染器的人；代码本身作者说「没什么意思」，真正的价值是配套的 14 篇讲义；不适合想做现代 GPU 应用开发的人（作者明确说不展示如何写 GPU 应用）。

codecrafters-io/build-your-own-x

★ 558.3k Markdown

「从零重建你喜欢的技术」的分步指南合集：3D 渲染器、AI 模型、增强现实、BitTorrent 客户端、区块链、数据库、Docker、操作系统、编程语言、数据库、网络栈、Shell、正则引擎、浏览器、Web 服务器等 30 多个技术，每个都有循序渐进的教程。

本质上是一个精选的「自己动手造轮子」教程索引，而非一个可直接运行的代码仓库。适合通过「从零实现」来学习底层原理的自学者；仓库本身只有 README 和几个配置文件，所有实质内容都在链出的具体教程里。选哪个技术、跑多远，完全由你决定。

donnemartin/system-design-primer

★ 376.4k Python

系统设计入门指南：帮你学会设计大规模可扩展系统，并准备技术面试中的系统设计环节。把散落在网上的资源组织起来，配有练习题、示例解答、代码和图表，支持多国语言翻译，还能生成 epub。

这是一个资源索引型仓库，核心价值在于「把系统设计知识组织好」而非「提供一套唯一标准答案」。适合准备系统设计面试、想系统学习大规模系统设计的工程师；有练习题和示例解答，适合边读边做；多语言翻译（含简体中文、繁体中文、日语、阿拉伯语等）体现社区贡献。

freeCodeCamp.org 的开源代码库与课程：由 501(c)(3) 慈善机构运营，提供完全免费、自学进度的全栈 Web 开发和机器学习课程，数千个交互式编程挑战，社区已帮助超过 10 万人拿到第一份开发者工作。
