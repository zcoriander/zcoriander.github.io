## 关于本索引

本索引中的所有文章均基于 GitHub 公开 API 数据整理，每篇深度拆解都包含：

- **它到底在做什么** —— 项目核心功能与定位

所有文章均已按照 `anvil-hugo-hexo` 的 `WikiFrontmatter` 规范进行 frontmatter 规范化，可直接用于内容验证与跨平台同步。
