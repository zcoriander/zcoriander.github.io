storytold/craft-anything

★ 19.3k Rust

Craft Anything：理解任何软件的工作原理，然后复刻属于你自己的版本。storytold 家族的又一 Rust 工具，主打从零重建主流创作软件的核心引擎。

craft-anything 不是给普通用户的工具，而是给「想亲手重建一遍」的开发者的实验场。如果你对 Rust 和软件底层原理感兴趣，值得关注；如果只想找个能用的软件，先绕道。

wangzan101/Mika

★ 7.5k Kotlin

在 Android 设备上本地运行的 AI Agent，能够操作 App 和浏览器帮你完成事情。主打 on-device，数据不出本机。

如果你关注 on-device AI Agent 方向，愿意在自己的 Android 设备上尝鲜，Mika 值得关注。它证明了「AI 操作手机」不一定需要云端，本地运行是可行的。但目前还不是日常好用的工具，更适合作为技术预览。

storytold/effectcraft

★ 8.5k Rust

纯 Rust 从零写的动效合成器，对标 After Effects。项目文件是 JSON，可脚本化、可版本控制，引擎命令走 CLI / JSON 控制通道 / MCP。

effectcraft 是「动效合成也可以是代码」的一个坚实尝试。如果你的工作流里需要大量重复性动效，或者希望动效文件能进 Git 管理，它值得一试。纯 Rust 实现也意味着性能和可移植性都有保障。

simbasjungles/free-my-tv

★ 6k Java

给 Google TV、LG webOS、三星 Tizen 等智能电视做的无广告开源首页替代方案。60fps，内存占用比系统首页少 60%，不用 root 即可安装。

free-my-tv 把「夺回电视主控权」这件事做得很扎实。无广告、低内存、不需要 root，这三点已经解决了智能电视用户最痛的问题。如果你的设备在受支持列表里，值得安装试试。
